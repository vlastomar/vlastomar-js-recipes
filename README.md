# RecipeShare — React Exam Project

## Step 1: Starter

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

This starter includes a home page, catalog placeholder, navigation and responsive styling. It does **not** yet include Supabase integration, authentication, CRUD, comments, route guards or a completed Functional Guide. These are planned for later steps.

## Next steps
1. Create Supabase project and database schema with RLS.
2. Connect API and load catalog.
3. Add authentication and protected routes.
4. Add CRUD and comments.
5. Test, document and deploy.
